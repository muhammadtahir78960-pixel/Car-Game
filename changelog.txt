🚗 Car Game v2.4 - What's New! 🏁
​📅 Last Update Date: August 18, 2026
​Welcome to the latest update of Car Game! We have packed version 2.1 with exciting new features, improvements, and bug fixes to elevate your gaming experience.
​🌟 Major Highlights & New Features
​🎁 Enhanced Daily Rewards
​Daily rewards now offer more than just fuel! You can now get additional inventory items like Gasoline and AI Pilot Chip.
​🛒 Shop Upgrades
​You can now upgrade the shop using diamonds to buy multiple items.
​🔊 New SFX
​Brand new sound effects (SFX) have been added to make the gameplay much more immersive.
​🛠️ Engine Health & Mechanic Shop
​An engine health system has been introduced in racing mode! If your engine health drops, you can get your vehicle repaired from the Mechanic Shop.
​🎙️ TTS Stream Channel
​A TTS stream channel has been added, allowing you to select it according to your preference.
​💾 Backup System Update
​The backup system has been updated to include additional profile data for better security.
​👤 Username Update
​Usernames have been standardized with updated rules:
​The character limit has been reduced/set to 20 characters.
​You can now use uppercase, lowercase, numbers, and special characters (., _, -).
​🌐 Online Profile Stats
​User ID and Tournament Host stats have been added to online profiles.
​💬 Global Chat Update
​50 reactions have been added to global chat, and you can now see who reacted to messages.
​🏆 Tournament Updates
​A Private Tournament button has been added to the tournament join screen, allowing creators and joiners to view tournaments without a code.
​Tournament creators can now select the race distance.
​Creators can delete tournaments after they end.
​Fixed an issue where the device would freeze while collecting tournament winning rewards.
​🔧 Improvements & Bug Fixes
​📱 UI Improvements: The User Interface (UI) has been improved for a smoother experience.
​🐛 Bug Fixes: Various bugs have been fixed.
​🚀 There is much more for you to explore and discover in the game!
